# Student-Social-Media-And-Mental-Health-Impact

## 📌 Project Overview
This project applies Machine Learning techniques to investigate and predict student mental health risk levels based on daily habits, social media usage, and sleep patterns. 

We approach this as a **Multi-Class Classification** problem, categorizing mental health status into three distinct risk categories: **Poor**, **Fair**, and **Good**.

## 🛠️ Tech Stack & Requirements

The project is built using Python and the following core data science libraries:

* **Python** (3.10+)
* **Pandas** & **NumPy** (Data manipulation and feature engineering)
* **Scikit-Learn** (Preprocessing, Random Forest, GridSearchCV, Metrics)
* **XGBoost** (Gradient Boosting Classification)
* **Matplotlib** & **Seaborn** (Data visualization & Confusion Matrices)
